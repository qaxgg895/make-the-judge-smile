One line, at most 200 characters, about a small good thing that happened today — something that would make a reader smile. Entry for the [Make the Judge Smile](https://make.fun/competitions/u-gentle-badger-68-make-the-judge-smile-9228676d) competition on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

It validates the line in code (1–200 characters, not only whitespace, single line, no control characters, no leading/trailing whitespace) and writes it to `/output/entry.txt`.
